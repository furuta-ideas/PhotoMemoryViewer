# PhotoMemoryViewer — メモリービューワー

指定期間の思い出の写真を1・2・3・4・6・8画面に表示するHTML5アプリです。写真を順番に入れ替え、YouTubeリンクがあれば1画面で動画を再生します。ライブラリのインストールやビルドは不要です。

## 起動

Node.js 20以上がある環境で、リポジトリのフォルダから実行します。

```sh
npm start
```

ブラウザで **http://localhost:5502** を開きます。終了はターミナルでCtrl+C。ポートを変更する場合は環境変数 `PORT` を設定します。付属サーバーはPC内だけの開発用で、外部ネットワークへ公開しません。

HTMLを直接ダブルクリックして開く方法はES Modules・認証・フォルダアクセスの制約があるため使用しません。静的ホスティングの場合は `index.html`、`styles.css`、`src/`、`docs/` をHTTPSで配信します。サーバーの公開作業は別途必要です。

## 写真を用意する

```text
思い出写真/
  20240403 （京都旅行）/
    IMG_001.jpg
    IMG_002.png
    video.url
  20250815 （夏休み）/
    beach.webp
    youtube.txt
```

「写真フォルダを選択」で `思い出写真` を選び、Playを押します。親フォルダ以下の有効な日付フォルダを再帰的に探索します。日付付きフォルダ自体を選んでも読み込めます。期間はフォルダ名の先頭8桁で判定し、開始日・終了日も含みます。空欄は期間制限なし。入れ子の場合は、最も近い有効な日付フォルダの名前を表示します。

- 画像：JPEG、PNG、WebP、GIF。HEIC / HEIFはJPEG等へ変換してください。
- YouTubeリンク：UTF-8の `.txt`（1行1URL）またはWindowsの `.url`。動画をダウンロードせずYouTubeの公式プレイヤーで再生します。
- `.txt` の例：`https://www.youtube.com/watch?v=VIDEO_ID`
- `.url` の例：

```ini
[InternetShortcut]
URL=https://youtu.be/VIDEO_ID
```

日付に合わないフォルダ、対応外ファイル、無効なURLはスキップし、設定画面で件数と理由を表示します。`.webloc`、ローカル動画ファイル、顔認識、複数ルート同時選択は未対応です。写真本体を外部へアップロードしたり、元ファイルを変更したりしません。

## 操作

- **Play / Stop**：再生／停止。Stopは現在の写真を保持します。空白キーでも切り替えできます（入力中を除く）。
- **設定**：左ペインを開閉。変更は「設定を適用」で反映します。適用後は周期を再開します。
- **全画面**：対応ブラウザでは全画面。iOS等の非対応環境ではブラウザ内の最大表示です。
- **リフレッシュ時間**：初期15秒、4～3600秒。4画面なら3.75秒ごとに1画面、各画面は15秒ごとに更新します。
- **写真表示**：初期は全体を表示。画面いっぱい（端が切れる）にも変更できます。
- **動画**：最大1画面、最後の領域を利用。動画自体を保ち、当該領域の更新時に再生位置を変更します。「次の動画」で別動画へ変更します。1画面設定では動画が全面になります。
- **音声**：YouTube音声は初期ON。ブラウザにブロックされた場合は動画内の再生操作を押します。埋め込み不可動画は別候補へ移り、全候補が失敗したら写真へ戻ります。
- **BGM**：利用権限のあるローカル音声を選択できます。動画の音声ON中はBGMを止めます。音楽ファイルは次回起動時に再選択が必要です。
- **サンプルで試す**：外部通信なしで風景イラスト8件を表示します。実際の写真ではありません。

YouTubeは録画済みのシーク可能な動画を想定しています。ライブ配信や再生位置を変更できない動画は対象にしないでください。広告や公式プレイヤーの操作UIを排除しません。動画の長さが15秒以下なら開始位置は0秒になります。

YouTubeの表示領域が200×200未満になる場合は動画を一時的に表示対象から外し、分割数の変更を案内します。写真はそのまま表示します。スマートフォンでは1～3画面等、領域の大きい配置を利用してください。画面を広げると動画を再び選択できます。

設定を閉じると写真が表示領域全体へ広がり、再生中の操作バーは3秒後に隠れます。タップ・マウス移動で再表示します。フォルダ名は各領域の中央下に、白い太字・影・黒グラデーションで表示します。動画は公式操作UIを覆わないようフォルダ名を上部に表示します。

## Windows / iPad / iPhone

WindowsのEdge / Chromeではフォルダ選択と読み取り許可を利用します。`C:\Photos` のパス文字列だけで読み取ることはできません。前回選択したフォルダは対応環境で保存し、次回の「再接続」で許可を確認します。非対応ブラウザでは階層付きファイル選択へ切り替えます。

iPad / iPhoneはGoogle Driveを推奨します。ウィンドウサイズ・画面回転に応じて分割配置を調整します。Safariの選択画面で階層が渡されない場合はGoogle Driveを使用してください。バックグラウンドや画面ロック中は再生を休止し、復帰後は更新周期を再開します。

## Google Drive

Google OAuthクライアントIDの発行とDrive APIの有効化が必要です。**[接続手順](docs/google-drive.md)** を参照してください。設定のGoogle DriveタブでフォルダURLとクライアントIDを入力して接続します。任意の既存フォルダを探索するため `drive.readonly` の読み取り権限を利用します。トークンは端末のメモリ内だけに保持します。

設定値は端末内のlocalStorageに保存します。Google DriveフォルダID・公開クライアントIDを含みますが、写真・アクセストークンは保存しません。端末間で同期しません。Google接続、YouTube再生ではそれぞれのサービスへ通信します。写真ソースの接続解除時にGoogle認可を可能な範囲で取り消します。

## Spotify

Spotify連携は仕様どおり保留です。公式Developer Policyでスライドショーとの同期、他音声との重複、他サービスとの統合に制限があるため、キーワード検索・SpotifyによるBGM再生を実装していません。ローカル音声BGMを代替として提供しています。

参照：[Spotify Developer Policy](https://developer.spotify.com/policy)、[YouTube IFrame API](https://developers.google.com/youtube/iframe_api_reference)、[MDN showDirectoryPicker](https://developer.mozilla.org/en-US/docs/Web/API/Window/showDirectoryPicker)。

## 検証

```sh
npm test
```

日付・フォルダ階層・抽選・URL解析・更新周期・ソース読み込み・Drive APIのページ送り／認証切れを検証します。ブラウザ検証手順・結果は [検証記録](docs/validation.md) を参照してください。Googleの実アカウント接続、YouTubeの実際の音声付き再生、iPad / iPhone実機は、認証情報と実機での確認が必要です。

ブラウザ自動テストは別途Playwrightが利用可能な環境で `npm run test:browser` を実行します（先にアプリサーバーを起動）。既存Playwrightの場所は `PLAYWRIGHT_MODULE`、Chrome等の実行ファイルは `PLAYWRIGHT_BROWSER_PATH`、一時フォルダは `PHOTO_MEMORY_TEST_DIR` で指定できます。画面出力は既定で `test-results/` に保存します。アプリ本体の実行にはPlaywrightは不要です。

## 構成

```text
index.html / styles.css   画面とレスポンシブ表示
src/core.js              日付、抽選、分割、更新タイマー
src/sources.js           ローカル、Google Drive、サンプル
src/youtube.js           YouTube IFrame Player
src/app.js               設定、画面、再生状態の連携
server.mjs               開発用のローカル静的サーバー
tests/                   Node.js標準の自動テスト
```
